# 📈 Week 3 — Exploratory Data Analysis & Foundational Machine Learning

> Week 3 was where raw data started turning into insight — and insight started turning into predictions. This week combined visual storytelling through EDA with the first real machine learning models of the bootcamp: regression and classification.

---

## 🔍 Advanced Exploratory Data Analysis (EDA)

Worked extensively with the **Titanic dataset**, one of the most well-known datasets in machine learning, to practice real-world data exploration techniques:

- Uncovering patterns, trends, and relationships hidden in raw data before modeling
- Visualizing distributions, correlations, and outliers using **Seaborn** and **Matplotlib**
- Building an intuition for *which* features actually matter for prediction — a skill more valuable than any single algorithm
- Preparing cleaned, visually-understood data as input for the classification task that followed

**Why it matters:** Advanced EDA is the step most beginners skip — but it's what separates a model that "just runs" from one that's actually built on a real understanding of the data.

---

## 🤖 Machine Learning: Regression & Classification

### 📐 Linear Regression
- Implemented linear regression from the ground up to predict continuous outcomes
- Worked through structured exercises validating model correctness against provided test cases
- Applied regression concepts to real-world style problems (including price prediction)

### 🧮 Classification — Titanic Survival Prediction
- Built a classification model to predict passenger survival on the Titanic dataset
- Applied the EDA insights directly into feature selection and model input
- Practiced the full workflow: explore → clean → visualize → model → evaluate

### 🚗 Car Prices Dataset — Regression & Classification
- Worked with a car prices dataset to practice both sides of supervised learning:
  - **Regression** — predicting car price as a continuous value based on features like mileage, age, and specifications
  - **Classification** — categorizing cars (e.g. price bracket or another target class) based on the same feature set
- Reinforced the difference between regression and classification problems by solving both on the same real dataset, rather than treating them as purely separate concepts

### 💡 Solved Example Walkthroughs
- Worked through additional guided example problems (including hiring/salary prediction) to reinforce regression concepts with fully worked solutions

---

## 🧠 Key Takeaways
- Comfortable visualizing and interpreting datasets using Seaborn and Matplotlib
- Understanding of how EDA directly informs modeling decisions
- Hands-on experience building both regression and classification models from scratch
- First full exposure to the end-to-end ML workflow: data → insight → model → prediction
