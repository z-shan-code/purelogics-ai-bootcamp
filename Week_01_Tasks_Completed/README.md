# Week 1 — Python Fundamentals & Data Preprocessing

## Overview
Week 1 laid the foundation for everything that followed in this bootcamp. The focus was on building strong core Python skills and learning how to clean, structure, and prepare raw data for downstream machine learning and AI workflows — a skill that turned out to be just as critical as any model-building technique later in the program.

## What This Week Covered

### 🐍 Python Fundamentals
- Core Python syntax: variables, data types, and operators
- Control flow — conditionals and loops for building program logic
- Functions — writing reusable, modular code blocks
- Working with Python's core data structures: lists, tuples, dictionaries, and sets
- String manipulation and formatting
- File handling — reading from and writing to files
- Debugging and understanding error handling in Python programs

### 🧹 Data Preprocessing
- Techniques for identifying and handling missing or inconsistent data
- Cleaning raw datasets to make them usable for analysis and modeling
- Structuring and transforming data into formats suitable for machine learning pipelines
- Early exposure to the mindset that "garbage in, garbage out" — most real-world ML problems start with messy data, not clean CSVs

## Why This Week Mattered
Every advanced concept covered later in the bootcamp — from machine learning models to LLMs and RAG pipelines — depends on solid data handling and clean Python fundamentals. This week wasn't just an "intro" phase; it was the base layer that made everything from Week 2 onward possible to build on confidently.
