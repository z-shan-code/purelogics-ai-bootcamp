# 🧬 Week 4 — Unsupervised Learning, Dimensionality Reduction & SVM

> Week 4 pushed beyond basic regression and classification into more advanced machine learning territory — unsupervised learning, dimensionality reduction, and one of the most powerful classical ML algorithms: Support Vector Machines. This week also introduced hyperparameter tuning as a real, hands-on practice rather than just a theoretical concept.

---

## 🧠 What This Week Covered

### 🎯 Support Vector Machines (SVM)
- Built and trained SVM classifiers on real datasets
- Compared a **default SVM model** against an **optimized/tuned SVM model**, analyzing learning curves to understand the impact of hyperparameter tuning on model performance
- Learned how SVMs find optimal decision boundaries for classification problems

### 🩺 Breast Cancer Dataset
- Applied classification techniques on the breast cancer dataset — a classic real-world medical diagnosis dataset used to predict whether a tumor is malignant or benign
- Practiced the full pipeline: data preparation → model training → evaluation on a dataset with genuinely high-stakes, real-world implications

### 🔗 K-Means Clustering
- Learned unsupervised learning through K-Means clustering — grouping data points based on similarity without labeled outcomes
- Applied K-Means on real datasets to identify natural groupings/patterns in the data

### 📉 Principal Component Analysis (PCA)
- Learned dimensionality reduction using PCA — reducing the number of features in a dataset while preserving as much meaningful information as possible
- Understood why dimensionality reduction matters for both model performance and data visualization in high-dimensional datasets

### ❤️ Additional Practice
- Applied these concepts across multiple datasets (including a heart disease dataset) to reinforce clustering and dimensionality reduction techniques in different contexts

---

## 🧠 Key Takeaways
- Understanding of the difference between supervised (SVM) and unsupervised (K-Means) learning
- Hands-on experience with hyperparameter tuning and interpreting learning curves to diagnose model performance
- Practical grasp of dimensionality reduction and why it matters before feeding data into a model
- Applied machine learning to a real medical diagnosis dataset — grounding classification work in a genuinely meaningful use case
